# Safe Spend — AI-assisted interactive prototype

A lightweight HTML/CSS/JavaScript prototype for a personal finance concept that helps people with irregular income understand a safe daily spending limit.

## What is included
- Onboarding
- Home / Safe daily spend screen
- Basic responsive layout
- Design tokens in CSS variables
- Simple client-side calculation
- Bank selection (the last screen of the prototype flow)

  **Not included yet**
- Actions after choosing a bank: the flow ends at bank selection
- Profile / settings screen (the profile icon on Home is a visual placeholder; the settings flow still needs to be designed)
- Loading, error, empty and success states
  
I chose to focus the time on the core idea and the main flow first. The missing parts are listed above on purpose, so it is clear what is designed and built and what is still open.

## My contribution
I defined the user problem, core scenario, user flow, visual hierarchy, component structure and states. I used an AI coding agent to accelerate HTML/CSS implementation, then reviewed, refined and verified the result manually.
